从 `wubu-pw.mysxl.cn` 抓下来的五个页面，**双击就能看，不联网也行**。

| 文件 | 原站路径 | 内容 |
| --- | --- | --- |
| `index.html` | `/` | 首页：恪守五不，讲好道法 / 核心价值观 |
| `2.html` | `/2` | 选择项目 / 购买评价手册 |

| `4.html` | `/4` | 历史评价成绩 |

## 怎么打开

双击 `index.html`，右上角导航可以在五页之间跳转。图片、图标、字体都在本地 `assets/` 里，断网也能正常显示。

## 相对原站点做的事

页面文字、排版、内容一个字没改，只做了下面四件事：

1. **站内链接改成本地文件**——原站用 `/`、`/2`、`/3`、`/4`、`/5` 这种无扩展名路径，存到本地会 404，现在分别指向 `index.html`、`2.html`、`3.html`、`4.html`、`5.html`。每页 20 条以上站内链接，全部有效。
2. **图片等资源下载到本地**——原页面用的是 `//user-assets.sxlcdn.com/...` 这类协议相对地址，`file://` 下会被当成磁盘路径，图片全裂。现在都下载到 `assets/`（118 个文件，约 13 MB）并改成相对路径。
3. **顶栏白底**——原站的白底由脚本在滚动时切换，本地没有那套脚本会一直透明，所以补了一条样式固定成白底。
4. **指向本地页的链接不再新开标签页**——原站用 `target="_blank"`，在本地会另开一个窗口。
5. **手机端导航**——原站移动端左上角有个三条杠按钮，点开是抽屉导航；本地版没有平台脚本，补了一套等价实现（按钮 + 抽屉 + 遮罩，纯 CSS/JS），桌面端的原导航不受影响。
6. **删掉了页脚**——每页底部的「关于我们 / 我们的使命 / 正在招聘！ / 资源 / 教程 / 品牌资料 / 联系我们」整块移除。
7. **竖屏适配**（`tools/data/portrait.css`，仅 `max-width: 767px` 生效）——原站在手机上本身就有毛病：成绩页图片格子写死 419px 宽（比 360px 的容器还宽，整页能横向拖动）、首页标题 36px 排不下被裁、按钮撑出边界。这些在桌面端完全不受影响。

## 已知的

- 顶栏的购物车图标没有：原站由脚本运行时插入，静态文件里没有这个标签。
- 主题样式表里有 3 处 Bebas Neue 字体仍指向原站（页面没用到这个字体，不影响显示）。

## 重新生成

```powershell
python tools/fetch.py         # 从原站抓取五个页面到 raw/
python tools/make_offline.py  # 下载资源、接站内链接、生成本地文件
python tools/mobile_nav.py    # 加手机端导航、删页脚
```
